Confirmed bottlenecks and disposition

1. All 888 MATERIAL_DEFERRED records have queued=flushed=0 despite enabled=1.
   The source required MSAA. Implemented ordered opaque-model capture batches
   for non-MSAA D24S8 scenes on the existing DXVK deferred-capability path.
   The normal-only native shader specialization from the preceding change is
   retained. The two changes address shader work and per-draw target switching.

2. Cold model subdivision occurs in 25 sampled frames: mean 3.306 ms,
   maximum 4.895 ms at frame 293497 (line 96016). Pose fallback reaches
   2.407 ms at frame 353187; boundsPose reaches 4.147 ms at frame 303784.
   Current HEAD already includes f18939ec (subdivision allocation optimization)
   and 7e3fa4ff (world-transformed pose / exhausted build slots), both later
   than this log's binary. Do not duplicate those fixes or claim a new measured
   improvement from this old capture. The new batching reuses a conservative
   far bound already computed by the geometry pose path, avoiding a second
   envelope evaluation when that proof is available.

3. Address-space pressure is real: minimum available virtual memory 388 MiB,
   minimum largest free block 34 MiB, 186 cumulative trims. The last sample
   has 509 MiB available and a 158 MiB largest block. One critical trim costs
   16.508 ms and releases an estimated 119.7 MiB (frame 296033, line 102318);
   its material work is 11.556 ms and world work 4.848 ms. Later empty trims
   can be as low as 0.030 ms. Asynchronous address-space walks reach 47.075 ms;
   this is worker sample time, not automatically render-thread blocking.
   Preserve critical-pressure release and the existing bounded queues. The new
   depth snapshot costs four bytes per pixel (3.52 MiB at 1280x720), uses the
   existing headroom policy, and falls back to immediate capture if allocation
   fails. Failed allocation retries are delayed 60 frames.

4. The 3.55-second slow frame 690 has applied=0 and 2912.803 ms of frame queue
   idle; frame 363297 has 3056.136 ms total and 2948.209 ms idle. These are not
   multi-second point-light shader executions. An idle gap at frame 294796
   lasts 1084.954 ms with only 15.625 ms observed producer CPU and negligible
   command-stream waits. The trace does not identify the application phase.
   A producer/application or I/O trace is required to attribute that remainder.
   Replay samples also contain Present calls around 36 ms (frames 259461,
   259588), which must be separated from active rendering work.

5. The command stream reports 35,879 cumulative texture readbacks near the
   end, with 16 MiB texture shadow capacity. The last 600-frame window has
   322 readbacks, 6.882 MiB transferred, and 45.267 ms total wait. The final
   replay sample spends 7.402 ms across 1193 UnlockBuffer calls, including one
   5.620 ms call. Memory pressure disables zero-copy and the log reports large
   cumulative copied traffic. These counts include very different frame
   regimes; they are not per-frame costs. Increasing retained shadow/ring
   budgets with only 34 MiB contiguous headroom is not a justified fix.
   Follow-up measurement should correlate UnlockBuffer outliers with driver
   upload waits and pressure transitions before changing buffer ownership.

6. Isolated timestamp spikes occur in unrelated passes: AOBlur, PointShadow
   and PointLight all exceed 8 ms around frame 259842; Fog reaches 22.279 ms
   at frame 315595. Timestamp duration includes GPU execution stalls. This
   capture alone cannot distinguish shader cost, driver scheduling and upload
   dependencies. Stable RemovalSmooth cost and crowded point-shadow submission
   remain candidates for a separate measured optimization. Their image quality,
   light counts and refresh cadence have not been reduced.

Batch correctness contract

A batch snapshots the currently bound native depth through DXVK RESZ into DF24,
then replays model captures in original order with their native depth comparison
and depth writes. EQUAL retains the prepass; LESS retains first-writer behavior.
A final-depth-only replay would fail those cases and is deliberately not used.
Conservative pose/position bounds must prove every vertex within capture range,
so range clipping cannot remove a depth write needed by a later packet.
Alpha-tested/blended models, shared POM, prepared displacement geometry,
unsupported depth formats, unknown bounds and unsafe snapshots keep immediate
capture. Existing MSAA admission and its private-depth EQUAL handling remain.
Batches finish before an uncaptured native draw, depth clear, target/depth change,
copy operation or guarded texture mutation. Immutable source and map leases,
packet budgets and resident/UP fallbacks reuse the existing deferred machinery.
New MATERIAL_DEFERRED fields singleSample, depthSeeds and depthBarriers make
actual batching and fragmentation visible in the next tester log.

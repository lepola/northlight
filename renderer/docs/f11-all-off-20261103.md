# F11 full pipeline stop — Windows 0.3.217

The build number stays **0.3.217** as requested. Identify this build by the source identity and DLL SHA256 in [the acceptance record](f11-all-off-20261103.json); the older QA capture also reported 0.3.217.

## Controls and behavior

F11 Overview now provides **All Northlight effects**, **World shadows**, **Atmospheric fog** and **Local light illumination**. The same component controls appear on their respective pages. The local-light checkbox preserves the saved light limit.

`Effects=0` pauses scene processing while retaining individual choices and reusable caches. Turning off all seven main scene groups (GI, world shadows, atmospheric fog, local lights, AO, materials and weather) enters the same bypass automatically. Only these group masters enter the aggregate; enabled child controls do not prevent the all-off bypass. F7/F8/F9 and F10 remain independent temporary switches; menu settings cannot override a temporary OFF switch. HDR presentation and the settings window remain available, as with F10.

Both F10 and F11 now use one effective `enabled` state. The disabled SDR path submits the original four Draw APIs without material, sky, weather, particle, name-mask or capture preparation. It also skips unused DrawArgs/geometry wrappers, weather updates, effect-budget polling and memory-sampling requests. Explicitly requested diagnostics retain their instrumentation path.

The world worker receives a disabled request. Geometry retries/cancellation and GI publication honor that state. A completed pending generation remains owned while paused, and the sleeping worker does not spin on it. Reactivation waits for the next current world request and retains reusable geometry/probe data. Stale memory samples are discarded when processing resumes.

Resource identity/revision bookkeeping, queued command delivery, frame cleanup/retirement, settings updates and required presentation remain active. They preserve native draws and safe reactivation; disabling scene work does not discard the renderer's device state or queued inputs.

## Offline comparison

The stand executes the actual production `Device` and all four Draw entry points, compiled with Windows x86 Zig 0.15.2 at O2. Baseline is frozen commit `74f6abc08a9d7d4f2658269ab63a5c5622ba4236`; only test friendship declarations are added to that tree. Its individual-off fixture uses the old component switches to disable the base components that the old menu could not disable.

For CPU measurements, the final backend Draw is a counted native stub; driver submission and GPU execution are excluded. A separate real DXVK render compares nonempty native images across F10, the F11 master and all seven F11 groups off. Frame-finish measurements execute `finishFrame`, after warm-up. Modes are rotated and both executables run in alternating order. There are six samples per mode. WoW coexistence was explicitly permitted; no game is launched, attached to or changed. These are component costs, not a game FPS prediction or a whole-scene replay.

## Validation

- Actual Device: original Draw counts/results, bit-identical real GPU images, paused queued request ignored, worker reactivation, cache ownership retained, requested diagnostics preserved.
- Quality policy: each of the seven groups can keep the scene active; the master OFF overrides all of them. Component hotkeys and menu masks are tested together, including reactivation.
- Budget controllers: OFF performs no timer polling or clock reads; ON resumes their normal behavior.
- Actual F11 panel: all pages render on private SDR/scRGB targets, including the new controls.
- WorldRenderer regression: MSAA 0/2, ordinary effects, HDR composition/fallback, memory admission, allocation recovery and probe restoration pass. One early pressure-fixture run missed its narrow VA band; the final strict rerun passes without weakening production memory admission.
- Production DLL and Windows package: built with the normal compiler/shader gates; installer payload, pins and checksums verified. Installed MPQs and Wow.exe are unchanged. Same-version installs compare payload hashes, so keeping 0.3.217 does not suppress the DLL update.

The acceptance JSON records full-suite results, any fixture-only rerun, artifact hashes and private evidence locations. Private evidence: `.local/out/f11-all-off-20261103/`.

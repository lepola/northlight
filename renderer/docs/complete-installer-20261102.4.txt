Performance changes
- Reuse the already computed current-palette SkinEnvelope instead of a second
  equivalent material bounds evaluation. Native O0/O2 checks cover 120 poses,
  shader DEF constants, source generations, exact bounds and budget refusal.
- Stop skinned depth-range preparation before fetching constants, declaration
  and source after the existing ready budget is exhausted. The old downstream
  evaluator necessarily refused that request. Frame reset restores eligibility.
- Skip local fog when every selected extinction coefficient is exactly zero.
  QA capture confirms all 64 lights have zero extinction in the actual shader
  banks; the accumulator is zero and before/after fog images are byte-identical.
  This removes 16 LocalFog draws, one combine draw and the accumulator clear in
  that scene. Direct lighting remains active; nonzero and unexpected values
  retain the previous fog path. No quality reduction or budget increase.

Diagnostics and limits
Bounded HDR fallback diagnostics now identify particle and sky call sites as
well as UI. HDR rendering itself is unchanged; this is not a claimed FPS fix.
Experimental AO and cloud shader edits were rejected after mixed GPU timings
or equivalence failure and were fully restored to the frozen source baseline.
Zig compiler preflight and the approved Windows build workflow remain in place
to avoid restricted-sandbox error: Unexpected.

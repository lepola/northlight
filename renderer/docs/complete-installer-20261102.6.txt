The .6 change
Small ready envelopes also use the existing fastReady path in the material
Stage::All pass. Each call has its own Timer, excluding unrelated game work
between draws from this cache's budget.
Owner, exact program key, current constants, camera, operation-count and time
checks remain. The new path is limited to 8 groups / 128 operations; cold and
heavy cases retain the existing evaluator.
Budgets, quality, effect distances and queued-frame count are unchanged.
No TargetFps was added. gxFixLag was restored as requested; Config.wtf matched
the original bytes after restoration.

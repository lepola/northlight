# Exact fog and cloud preparation, 2026-10-30

Cloud startup evaluates three Perlin octaves for every voxel in a 64-cubed noise volume. Four aligned X voxels share the same gradient cube at each authored period (4, 8 and 16). Evaluate those four lanes together, read each cube's gradients once, and preserve every lane's multiply/add and interpolation order. Keep the existing Worley work, normalization, noise size, quantiles, weather policy and asynchronous worker. A compile-time alignment invariant protects the shared-cube assumption. Scalar targets retain their original generator.

Regional fog also scans all 4,096 texels to find global vertical support. Process four texels at a time: reject unknown data through integer exponent checks before floating comparisons, transpose the batch, mask nonpositive layer tags and reduce the valid grounds/heights. Fold from positive zero to preserve the original signed-zero tie rule. Any nonfinite component still returns unknown support, keeping the full fog march. Scalar targets retain the original reduction.

These are preparation optimizations. Cloud generation runs when the worker first produces its shared noise volume; global bounds run when a regional field is published/uploaded. They are not reductions in steady-state raymarch steps or a demonstrated game FPS improvement. Shader source, bytecode, samplers, GPU targets, transfer size, visibility decisions, retry behavior and memory reserves are unchanged. Output/scratch allocations are unchanged; the new temporaries are bounded stack values and immutable gradient data.

The frozen oracle checks 3,145,728 Perlin lane results, 16 complete volumes (4,194,304 exact bytes) across four seeds and every rounding mode, and 18,004 field-bound cases. Field tests include signed zero, subnormals, NaN payloads, infinity, invalid metadata at every SIMD boundary, floating exception flags, and DAZ/FTZ controls. A separate build disables the SIMD paths, and ASan/UBSan cover the optimized implementation. Earlier whole-noise and field oracles remain unchanged.

Paired ABBA timings have four warm-up blocks and eight retained samples per implementation; timing has no pass threshold. The rounding-aware Windows x86 oracle measured cloud generation at 11.997 to 6.621 ms (44.81% less time), and a representative mixed fog field at 2.392 to 2.116 microseconds. A separate shipping-flags x86 generation pipeline control measured 8.115-8.207 to 3.747-3.796 ms over three runs (about 54% less time); the corresponding field control measured about 4% less reduction time. Floating-environment flags account for different absolute timings. These isolated figures do not measure a whole upload, login or frame.

Reproduce with `python tests/test_fog_simd_preparation.py` on a native Clang host. For the actual Windows x86 target, compile the companion C++ fixture with the renderer's Zig target and `-ffp-contract=off -frounding-math -UNDEBUG`, then run it with `--benchmark`.

Rejected experiments are excluded from production: packed CPU cloud interpolation, coordinate SIMD, density-dependent lookup pruning, and an ambient-only cloud shader. Their tests found slower/profile-dependent CPU work or mixed GPU performance (including a dense-cloud regression). The shader candidate also introduced small RGB rounding changes. No rejected shader or unfinished experiment is shipped, and no in-game measurement was made.
